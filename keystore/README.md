# مفاتيح توقيع الإصدار

لا يحتوي هذا المجلد على أي مفتاح توقيع، ولا يجوز إضافة مفاتيح `p12` أو `jks` إليه. المفاتيح المودعة في Git تعتبر مكشوفة حتى لو حُذفت لاحقًا.

ينشئ CI الملف المؤقت `keystore/ci.p12` من السر `USBMEDIA_KEYSTORE_B64`، ثم يمرر `USBMEDIA_KEYSTORE_PATH` وكلمات المرور والاسم المستعار عبر متغيرات البيئة. بناء `release` يجب أن يفشل عند غياب أي منها. راجع قسم «إعداد توقيع الإصدار» في `README.md` (جذر المستودع) لإنشاء مفتاح جديد وحفظه في أسرار المستودع.
