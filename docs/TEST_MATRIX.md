# مصفوفة اختبارات جهازية/يدوية - USB Media Explorer

> هذه القائمة مخصصة للجلسات التي تُجرى على جهاز حقيقي أو محاكٍ متقدم.
> هدفها: تحويل كل خطر أو نقطة حرجة في المشروع إلى سيناريو اختبار محدد وقابل للتكرار.

---

## 1. كيفية استخدام القائمة

كل صف يحتوي على:
- السيناريو: ما الذي نجربه
- المتنبأ به أو المعيار: ماذا نتوقع
- الحالة المتوقعة: ما الذي يجب أن يحدث فعلًا، بما في ذلك الرسائل الموجّهة للمستخدم وسلوك الواجهة
- ملاحظات: أشياء قد تحتاج معرفة مسبقة

لا يُفترض أن كل الاختبارات ستنجح بالضرورة على كل جهاز؛ بعضها يكتشف اختلاف OEM. الأهم هو التوثيق.

---

## 2. فئة: التخزين والوصول (SAF والوحدات)

| السيناريو | المتوقع | ملاحظات |
|---|---|---|
| وصل فلاشة USB عبر OTG | تظهر الوحدة في الرئيسية بحالة "يحتاج إذن" إذا لم يُمنح بعد | السماح بمنح SAF على الوحدة |
| منح SAF على الوحدة | تختفي حالة "يحتاج إذن" وتصبح READY؛ تظهر الأسماء/المساحة إذا وجدت | مراقبة plausibleStatFs |
| إعادة تشغيل الجهاز ثم فتح التطبيق | تظهر الوحدة READY دون طلب إذن جديد إن وُجد persisted grant | ملاحظة OEM/java |
| فصل الوحدة أثناء التصفح/التمرير | تظهر رسالة خطأ مناسبة ولا يتعطل التطبيق | قد يحتاج التمرير بعدها للعودة |
| وحدة FAT32 وexFAT | تظهر تسمية النظام بشكل سليم أو "—" إن لم يتوفر | قد يختفي أحيانًا حسب `/proc/mounts` |
| محاكاة وحدة كبيرة مع عدد كبير من الملفات | لا تعلق الواجهة، المعاينات-loader تدريجي | قد يحتاج اختبار حد 15000 |
| وحدة لم يكن المسار المكشوف بصلاحية القراءة | تظهر "المساحة غير متوفرة" بدلاً من قيم كاذبة | |

---

## 3. فئة: المشغل والوسائط

| السيناريو | المتوقع | ملاحظات |
|---|---|---|
| تشغيل فيديو من USB مباشر | يبدأ التشغيل دون نسخ | تأكد من عدم إنشاء ملفات جانبية |
| فيديو مع ترجمة مدمجة + ملف SRT جانبي | يجب أن يكون تحديد الترجمة ممكنًا | جودة الكود تحتاج تأكدًا عمليًا |
| فصل الوحدة أثناء التشغيل | يظهر خطأ مصنف (SOURCE_UNAVAILABLE أو ما شابه) ويوفر خيار إغلاق / إعادة فتح | |
| ملف تالٍ أو غير مدعوم | لا يتعطل التطبيق؛ تظهر رسالة غير مشفرة | ربما تختلف حسب الترميز |
| HEVC / HEIF / GIF | المعاينات والتشغيل يعتمدان على دعم النظام | اختلاف OEM يجعل النتائج النظرية بلا قيمة دون جهاز حقيقي |
| إطار فيديو مُستخرج من الفلاشة وليس من داخل الهاتف | لا يوجد ملف وكيل جانبي؛ logcat يوضح المصدر | |

## 4. فئة: عمليات الملفات والنقل

| السيناريو | المتوقع | ملاحظات |
|---|---|---|
| نسخ مجلد كبير بين وحدتين | يظهر إشعار تقدم، يمكن إيقاف مؤقت/استئناف/إلغاء | |
| نسخ بين وحدات مختلفة (cross-volume) | staged copy ثم حذف المصدر بعد الالتزام | |
| محاولة نسخ مجلد إلى نفسه أو إلى أحد فروعِه | يُرفض العملية برسالة واضحة | |
| استخدام ضغط ZIP أو أرشيف ضخم | يستخدم مساحة وسيطة؛ يجب الإبلاغ الواضح أو إظهار الخطأ عند تجاوز الحد | |
| حذف مجلد بمحتوى كبير | يجب أن يظهر سلوك متوقع ولا يترك ملفات وسطية | |
| محاولة استخراج ملف Zip يحتوي مسارات `".."` | zip-slip مُرفض دون الهروب من الوجهة | |
| جر try في نسخ أو نقل أو ضغط عند انقطاع USB | لا يبقى ملف نصفي كامل عرضًا للوجهة النهائية; Fail واضح | |
| استئناف عملية بعد إيقاف مؤقت | يستمر من الموضع الذي توقف عنده مع تحديثات ETA/السرعة | |

## 5. فئة: الواجهة واللغة العربية/الإمكانية

| السيناريو | المتوقع | ملاحظات |
|---|---|---|
| تبديل اللغة إلى العربية داخل التطبيق | تظهر النصوص العربية في كل الشاشات | ترجمة كاملة مطلوبة |
| وضع RTL | الأعمدة والاتجاه يعملان صحيحًا حسب الأوضاع | الحجم والخط مهم |
| حجم خط كبير (200%) | لا يتداخل النص أو يُختفي | هذا اختيار يدوي |
| قارئ الشاشة (TalkBack) | الأزرار والكروت لها contentDescription مناسب | |
| شاشة فارغة/تحميل/خطأ | عرض الحالات بوضوح بصريًّا | |
| مجلد به فيديوهات كثيرة | شبكة كبيرة تعمل بدون تعليق غير متوقع | |
| ملفات ذات أسماء غير ASCII/عربية | لاترتب وأداء مقبول في الفرز والبحث | |

---

## 6. حالات حدودية (Edge cases)

- محاكاة انقطاع أثناء مرور معاينة أو مشغل طويل.
- وحدة بدون مساحة كافية لنسخ/ضغط.
- ملفات بأسماء متطابقة في الوجهة (اختيار الاسم الفريد).
- محاولة فتح فيديو من تطبيق آخر ثم الرجوع.
- داخل وضع الطيران: التطبيق يعمل بالكامل دون انترنت كما وعد.
- كشف ذاكرة المصغرات وحجمها المحدود، والإلغاء اليدوي.
- محاولة استخدام التطبيق مع وحدتين متصلتين متعددة.

---

هذه القائمة مقصود منها أن تكون مرجعًا تُضاف إليه نتائج حقيقية بعد كل جلسة اختبار جهازية، وليس وعدًا بأن كل نقطة ستظهر مُثبتة اليوم.
