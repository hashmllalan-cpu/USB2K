# USB Media Explorer

> تطبيق أندرويد احترافي لتصفح وإدارة الملفات والوسائط على وحدات USB وOTG وSD والتخزين الداخلي.

## نبذة عن التطبيق

يقدم USB Media Explorer تجربة قريبة من مديري الملفات المكتبية بواجهة أندرويد حديثة، مع تركيز خاص على مكتبات الأفلام والصور والموسيقى الموجودة على وحدات التخزين الخارجية. يقرأ التطبيق الملفات مباشرة من المصدر ويعرض معاينات حقيقية للصور والفيديو دون نسخ الوسائط إلى الهاتف.

التطبيق مبني باستخدام Kotlin وJetpack Compose وMaterial 3 وMedia3/ExoPlayer وCoil، ويعتمد على Storage Access Framework للوصول الآمن إلى وحدات التخزين الخارجية.

## الميزات الرئيسية

### إدارة وحدات التخزين

- دعم USB Flash وUSB OTG وUSB SSD/HDD عند دعم الجهاز لها.
- دعم بطاقات SD والتخزين الداخلي وأنظمة FAT32 وexFAT عند توفر مزود النظام.
- اكتشاف الوحدات وتحديث حالتها عند التوصيل والفصل وإعادة التوصيل.
- استخدام SAF لمنح الوصول إلى الوحدات الخارجية والاحتفاظ بالإذن عندما يسمح Android بذلك.
- عرض اسم الوحدة والمساحة المستخدمة والمتاحة ونوع نظام الملفات.

### تصفح الملفات والمجلدات

- عرض قائمة أو شبكة بأحجام متعددة.
- Breadcrumb للعودة السريعة إلى المجلدات السابقة.
- فرز وتصفية وبحث تدريجي قابل للإلغاء.
- تحديد متعدد مع نسخ ونقل وحذف وإعادة تسمية ومشاركة.
- إنشاء ملفات ومجلدات، ضغط وفك ضغط، مفضلة، اختصارات، وتفاصيل العناصر.
- دعم الأسماء العربية والإنجليزية واتجاه RTL.

### معاينات الوسائط

- استخراج إطارات حقيقية من ملفات الفيديو الموجودة على وحدة التخزين.
- عرض الصور الأصلية كمعاينات بدل الأيقونات.
- إنشاء أغلفة للمجلدات من صور موجودة داخله عند تفعيل الخيار.
- تحميل كسول للمعاينات أثناء التمرير.
- تخزين المعاينات في Cache مستقل يعتمد على URI والحجم وتاريخ التعديل.
- دعم صيغ الفيديو والصور والصوت والترجمات التي يدعمها النظام وMedia3.

### المشغل وعمليات الملفات

- تشغيل الفيديو والصوت مباشرة من URI المصدر وقائمة تشغيل للمجلد.
- استئناف الموضع السابق والتحكم بالسرعة ونسبة العرض والترجمات الخارجية.
- تصنيف أخطاء التشغيل إلى مصدر غير متاح أو صلاحية مفقودة أو ترميز غير مدعوم أو خطأ غير معروف.
- إجراءات واضحة لإعادة المحاولة والعودة والفتح بتطبيق آخر.
- نسخ ونقل مرحليان مع أسماء مؤقتة مخفية، ومنع النسخ إلى المصدر أو أحد أحفاده.
- سجل عمليات دائم بحالات STAGING وCOMMITTED وFAILED.
- تحقق بالحجم، وتحقق SHA-256 اختياري للملفات الصغيرة قبل تثبيت الوجهة.

## البنية التقنية

```text
Compose UI / Material 3
        │
Screens + ViewModels + Navigation
        │
DocRepository / DocProvider
   ┌────┴─────┐
File provider  SAF provider
        │
USB / SD / Internal storage
```

- الواجهة: Jetpack Compose ومكوّنات تصميم موحدة للألوان والمسافات والأشكال والحالات.
- التنقل: Navigation Compose مع `launchSingleTop` و`restoreState` وسياسة Breadcrumb.
- التخزين المحلي: مخازن JSON صغيرة مع schemaVersion ونسخ احتياطية واستعادة من الملفات التالفة.
- التشغيل: Media3/ExoPlayer.
- العمليات: محرك تدفق، سجل دائم، خدمة أمامية، ومراقبة تقدم.
- الاختبارات: اختبارات JVM، مزودات Fake، اختبار Smoke على Android، وبوابة محاكيات API 29 و35.

## الأمان والخصوصية

- أزيل مفتاح التوقيع المكشوف ومسار signing الاحتياطي من المصدر.
- توقيع Release يتطلب أسرارًا خارج المستودع ومتغيرات بيئة صريحة.
- أزيل تصريح `MANAGE_EXTERNAL_STORAGE` من Manifest؛ المسار الأساسي هو SAF وصلاحيات الوسائط المطلوبة فقط.
- التطبيق لا يملك خدمة شبكية أو Telemetry سحابية افتراضية.
- لا ينبغي تسجيل أسماء الملفات أو URI أو المسارات أو محتوى المستخدم.
- يجب حماية أسرار CI وتدوير المفتاح المكشوف وحماية وسوم الإصدار والفروع.
- بيانات التطبيق المحلية تشمل المفضلة والملفات الأخيرة ومواضع التشغيل؛ إزالة التطبيق قد تحذفها، بينما لا تتأثر الملفات الأصلية على وحدات التخزين.

## البناء والتشغيل

المتطلبات: JDK 17 وAndroid SDK 36 وبيئة Gradle قابلة للتنفيذ.

```bash
./gradlew --version
./gradlew :app:assembleDebug --no-daemon --console=plain
./gradlew :app:testDebugUnitTest --no-daemon --console=plain
./gradlew :app:lintDebug --no-daemon --console=plain
./gradlew :app:connectedDebugAndroidTest --no-daemon --console=plain
```

للتشغيل الكامل يلزم جهاز أو محاكي Android.

## إعداد توقيع الإصدار

لا تستخدم أي مفتاح منشور سابقًا. ولّد مفتاحًا جديدًا خارج المستودع:

```bash
keytool -genkeypair -v \
  -keystore usbmedia-new.p12 \
  -storetype PKCS12 \
  -keyalg RSA -keysize 4096 -validity 10950 \
  -alias usbmedia \
  -dname "CN=USB Media Explorer, OU=Dev, O=USB Media Explorer, C=YE"
```

خزّن الملف وكلمات المرور في مدير أسرار أو HSM، ثم أضف أسرار GitHub:

```bash
base64 -w0 usbmedia-new.p12 > keystore.b64  # macOS: base64 -i usbmedia-new.p12 -o keystore.b64
gh secret set USBMEDIA_KEYSTORE_B64 < keystore.b64
gh secret set USBMEDIA_STORE_PASSWORD
gh secret set USBMEDIA_KEY_ALIAS
gh secret set USBMEDIA_KEY_PASSWORD
rm -f keystore.b64
```

المتغيرات المطلوبة هي `USBMEDIA_KEYSTORE_PATH` و`USBMEDIA_STORE_PASSWORD` و`USBMEDIA_KEY_ALIAS` و`USBMEDIA_KEY_PASSWORD`. يتحقق من APK بعد البناء باستخدام:

```bash
apksigner verify --verbose --print-certs app/build/outputs/apk/release/app-release.apk
```

بعد تدوير المفتاح قد تتطلب النسخة الجديدة إزالة تثبيت النسخة الجانبية القديمة. لا تتأثر الملفات الأصلية على USB أو SD أو الذاكرة الداخلية، لكن بيانات التطبيق المحلية قد تُحذف مع إزالة التثبيت.

## الاختبارات والتحقق

- اختبارات وحدات لتصنيف أخطاء المشغل، ترحيل JSON، سلامة SHA-256، وميزانية البحث، وقواعد المعاينات، والمسارات.
- `FakeDocProvider` و`FakePlayerFacade` و`TestClock` لعزل الاختبارات عن USB وMedia3 والوقت الحقيقي.
- اختبار Android Smoke لإقلاع MainActivity.
- تشغيل `connectedDebugAndroidTest` على API 29 و35 داخل Verify.
- اختبار يدوي على Android 11 و13 و14/15، هاتف وtablet، RTL، TalkBack، حجم خط 200%، FAT32/exFAT، USB بطيء وSSD، فصل الوحدة أثناء النسخ أو التشغيل، ملفات وسائط تالفة وغير مدعومة، ومجلدات تحتوي 1,000 و10,000 ملف.

## المخاطر والمتطلبات المتبقية

- تشغيل GitHub Actions والتحقق من حماية الفروع والوسوم وصلاحيات الوظائف.
- إدخال أسرار التوقيع المدورة والتحقق من بصمة APK.
- تنفيذ الاختبارات على USB فعلي ومصفوفة الترميز.
- قياس Macrobenchmark وBaseline Profile على جهاز مرجعي.
- لا توجد قاعدة بيانات أو Backend أو مزامنة سحابية في المشروع الحالي؛ هذه وظائف مستقبلية وليست جزءًا من التطبيق الحالي.
